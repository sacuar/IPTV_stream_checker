M3U Stream Checker V2

New features:
- Green-first and red-first sorting
- Show working only, failed only, slow only, waiting, or checking
- Optional "Only checked/scanned" filter
- Copy one or multiple selected links
- Copy selected entries as valid M3U text
- Save one or multiple selected channels
- Edit selected channel name, URL, and group
- Delete selected rows
- Pause and resume checking
- Save all working and slow streams as a clean M3U playlist

Run:
Double-click run_m3u_checker.bat
